# 解语

从零手写的 AI 推理框架（纯 C++17，header-only，无第三方依赖）。

由于是纯CPU所以可以直接使用GCC编译,不是nvcc

我从国庆1号开始敲到了7号，期间用了AI，因此留下了 ~~屎山~~ 一点小小的技术问题

本项目为了给推理提速，目前已经撞上了内存墙

如果你在测试过程里发现奔溃，报错等现象清前往[#1](https://github.com/Lenjing2026/jieyu/issues/1)进行反馈

指令使用请看[命令行参考](https://github.com/Lenjing2026/jieyu/wiki/%E5%91%BD%E4%BB%A4%E8%A1%8C%E5%8F%82%E8%80%83)
